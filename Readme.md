# 🛒 Amazon Clone

A frontend **Amazon homepage clone** built using HTML5 and CSS3.

## ✨ Features

- Amazon-style navigation bar
- Search bar and category selector
- Hero banner
- Shopping/category sections
- Product cards
- Footer section
- Hover effects and Flexbox layout

## 🛠️ Tech Stack

- HTML5
- CSS3
- Font Awesome

## 📂 Project Structure

Amazon_clone/
├── images/
├── index.html
├── style.css
└── README.md


## 🚀 How to Run

1. Clone the repository git clone https://github.com/AkhileshYadav117/Amazon_clone.git
2. Open index.html in your browser

Or use **Live Server** in VS Code.

## 🎯 Purpose

Built to practice **HTML, CSS, Flexbox, webpage layouts, and frontend UI development**.
