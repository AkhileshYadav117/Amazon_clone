# 🛒 Amazon Clone

A frontend **Amazon homepage clone** built using **HTML5 and CSS3**.  
This project recreates the look and structure of Amazon's e-commerce homepage, including the navigation bar, search section, hero banner, shopping categories, and footer.

> 📚 This project was created for learning and practicing frontend web development, HTML structure, CSS styling, Flexbox, layouts, and UI design.

---

## 🌐 Project Overview

The Amazon Clone is a static frontend project designed to replicate the visual structure of an Amazon-style e-commerce website.

The project includes:

- Amazon-style navigation bar
- Location and delivery section
- Search bar with category selector
- Account and Lists section
- Returns & Orders section
- Shopping cart section
- Secondary navigation panel
- Hero banner
- Shopping/category cards
- Footer with multiple sections
- Amazon-style colors and layout

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling and layout
- **Flexbox** – Navigation, panels, and shopping layout
- **Font Awesome** – Icons
- **JPG / PNG** – Website images and visual assets

Font Awesome icons are loaded through the CDN included in the HTML file.  
```
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.3.1/css/all.min.css">
```

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Amazon-Clone.git
```

### 2. Open the Project

Navigate to the project directory:

```bash
cd Amazon-Clone
```

### 3. Run the Website

Open `index.html` directly in your browser.

You can also use the **Live Server** extension in VS Code for easier development.
